DOCTOR PRESCRIPTION WEBSITE

1. Open this folder in VS Code.
2. Open Terminal.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open: http://127.0.0.1:5000

LOGO:
Replace static/logo-placeholder.svg with your own logo by changing the image source in templates/index.html,
or rename your PNG/JPG to logo.png and change:
logo-placeholder.svg
to:
logo.png

This is a front-end/local prescription form. For real patient use, add appropriate authentication,
secure storage, privacy protections, audit logging, and local medical/regulatory compliance.
